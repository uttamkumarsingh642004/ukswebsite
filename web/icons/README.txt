Generate your app icons here!

You can use online tools to generate icons:
1. https://icon.kitchen/
2. https://www.favicon-generator.org/
3. https://realfavicongenerator.net/

Required icon files:
- Icon-192.png (192x192)
- Icon-512.png (512x512)
- Icon-maskable-192.png (192x192)
- Icon-maskable-512.png (512x512)

Also generate a favicon.png (32x32 or 64x64) and place it in the web/ directory.

For now, Flutter will use default icons if these are not present.
